# 작업에 필요한 환경이나 도구가 없을 때

프로젝트 의존성 설치, 가상환경 설정, 임시 실행 바이너리 다운로드처럼 사용자 권한으로 간단히 해결하고 되돌릴 수 있는 문제는 자율적으로 복구한 뒤 작업을 계속한다.

인증·권한이 필요하거나 시스템 설정을 변경해야 하거나, 정해진 도구·절차를 벗어나야 한다면 작업을 멈춘다. 이때 막힌 이유와 발생한 오류, 사용자가 해야 할 조치를 설명하고 실행을 위임한다.

# 공인 IP 주소 노출 주의

에이전트 지침, 스킬, 프로젝트 문서 등 작성 시 공인 IP 주소를 기입하지 않도록 주의한다. 사설·내부 IP 주소와 서브넷 CIDR은 필요에 따라 기입한다.

# 비밀 관리

비밀 정보는 Bitwarden으로 관리한다. 개인 비밀 정보에는 `bw`를, Vivident 비밀 정보에는 `bw-vivident` 별칭을 사용한다. 작업에 꼭 필요한 비밀 정보만 조회해 사용하는 도구에 직접 전달한다.

## 쿠버네티스

`kubectl` 등 명령어 사용 시 반드시 다음과 같이 컨텍스트를 명시하여 사용한다. 현재 컨텍스트를 신뢰하지 않는다.
```bash
kubectl --context <context>
```
