# 오시즈 Sentry

운영 서비스의 오류·성능·네이티브 크래시를 Sentry 로 추적한다.

| 프로젝트        | 용도                                                          |
| --------------- | ------------------------------------------------------------- |
| `capacitor`     | OSHiZ Capacitor 앱의 iOS dSYM 업로드와 네이티브 크래시 심볼화 |
| `oshiz-backend` | OSHiZ 백엔드의 오류·트레이스 수집                             |
