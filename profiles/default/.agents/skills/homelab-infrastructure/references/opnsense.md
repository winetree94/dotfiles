# OPNsense 관리 가이드

필요 시 `ssh opnsense` 명렁어로 접근하여 설정을 변경한다. 작업 전 설정을 읽기 전용으로 확인하고 백업을 남긴다. 백업/복원 시 유실될 수 있는 스크립트나 설정 파일은 내부에 만들지 않는다. VPN 이나 인터넷 연결이 끊어질 수 있는 작업은 대체 접근 수단을 확보한 후 진행한다.

---

## 보안 규정

- 공인 IP 주소로 접근 가능한 서비스는 VPN으로 한정한다.
- 이외에는 반드시 Cloudflare Tunnel 을 사용해 공인 IP를 노출하지 않는다.
- 공개 DNS(*.winetree94.com) 에는 공인 IP로 직결되는 레코드를 만들지 않는다.
- 내부망에서 공개 주소로 접근 시 불필요하게 Cloudflare Tunnel 을 거치지 않도록 내부용 DNS 라우팅을 구성한다.
- 방화벽 규칙은 요구사항에 필요한 최소 권한만을 할당한다.

---

## 외부 DNS 및 터널 설정

Cloudflare DNS와 Tunnel은 설치된 `cf` CLI로 관리한다. `cf --help`, 하위 명령 도움말, `cf schema --help`로 현재 명령을 확인하고, 변경 전에 계정·프로필, 영역, 호스트명, 터널 식별 정보와 커넥터 상태를 확인한다. 가능한 경우 프로필·영역을 명시한다.

---

## 비비던트 네트워크와의 연결

홈랩 클러스터의 Tailscale Pod 를 게이트웨이로 사용하여 비비던트 내부망 IP 대역(`10.78.0.0/16`, `10.79.0.0/16`) 접근을 중계한다.


---
## VPN

opnsense 의 wireguard 플러그인을 통해 외부에서의 주요 내부 접근 수단으로 활용한다. tailscale 은 백업용 비상 접근 수단으로써 함께 유지한다.
