# Doppler 관리

회사 운영 서비스의 비밀, 환경변수 관리는 Doppler 로 관리한다.
`doppler` CLI 도구를 사용해 관리할 수 있다.

작업 전 반드시 다음처럼 `vivident` 워크스페이스인지를 점검한다.

```bash
$ doppler me
┬──────┬─────────────────────────────────┬
│ TYPE │ WORKPLACE                       │
┼──────┼─────────────────────────────────┼
│ cli  │ vivident (aaa51d12c96160a53107) │
┴──────┴─────────────────────────────────┴
```

워크스페이스가 다르거나 인증이 만려된 경우, 작업을 중단하고 사용자에게 다음의 인증 절차를 안내한다.


```bash
$ doppler login
```
