# Tinyrack Docs 업스트림 연동

소비자 저장소의 변경과 검증은 그 저장소의 `AGENTS.md`와 저장소 스킬을 따른다. 설치된 `@tinyrack/docs` 배포 릴리스와 공개 API를 기준으로 사용하며 `node_modules`나 미배포 체크아웃을 수정해 우회하지 않는다.

배포 릴리스만으로 해결할 수 없는 재사용 가능한 버그·기능 부족·프레임워크 동작을 발견하면 다음 절차를 따른다.

1. 소비자 작업을 멈추고 소비자 설정·콘텐츠만으로 해결할 수 없는 이유와 필요한 API·설정·동작, 호환성 범위를 정리한다.
2. 업스트림 변경이 이미 승인된 범위가 아니면 사용자의 명시적 승인을 받는다.
3. 업스트림 저장소의 `AGENTS.md`와 적용되는 저장소 스킬을 읽고, 최신 기준의 격리된 작업 트리에서 그 지침에 따라 구현·검증한다.
4. 저장소 지침에 따라 PR을 열고 리뷰와 필수 CI를 통과시킨 뒤 병합·릴리스한다.
5. 정확한 `@tinyrack/docs` 배포 버전과 아티팩트를 확인하고 업스트림 작업 트리를 정리한다.
6. 소비자 저장소로 돌아와 의존성과 잠금 파일을 배포 버전으로 갱신하고, 중단했던 문서 작업과 소비자 검증을 완료한다.

업스트림 구현·검사·릴리스의 구체적인 파일, 명령, 브랜치, 태그와 패키지별 규칙은 이 스킬에 복제하지 않는다.
