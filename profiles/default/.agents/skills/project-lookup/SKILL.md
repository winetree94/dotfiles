# Project Lookup

Read [references/projects.md](references/projects.md) for known locations and
recorded conventions. An explicit user path takes precedence. Verify that a
checkout exists and read its current project instructions before work; historical
paths and conventions are not proof of the current state.

Keep application development separate from infrastructure operations. For an
actual deployment or infrastructure task, select the environment skill using the
explicit repository, context, host, or deployment configuration. An ambiguous
service name or organization name alone does not identify a cluster.
